# Done Specs

One file per nontrivial task, created by the `define-done` skill before work
starts. Three lines — **Outcome / Done when / Judged by** — plus an optional
`## Unknowns` table appended by the `find-unknowns` skill.

Naming: `YYYY-MM-DD-<slug>.md`. Specs are living documents: when reality
contradicts the spec mid-build, update the spec and note it in the journal.
